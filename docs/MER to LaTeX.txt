Mathematical expressions recognition (MER) to LaTeX
1. Mục tiêu
Xây dựng hệ thống Deep Learning có khả năng nhận dạng biểu thức toán học từ ảnh (Math Expression Recognition - MER) thành mã LaTeX chính xác, sau đó kiểm tra tính tương đương toán học bằng SymPy.
Quy trình tổng thể (pipeline):
Ảnh → LaTeX → kiểm tra tương đương bằng SymPy
* Input: 
* Ảnh viết tay hoặc chữ đánh máy định dạng jpg, về công thức toán học, phương trình toán học, có thể là công thức chứa ẩn hoặc công thức tính toán
* Output: 
* dạng Latex của công thức
* giá trị rút gọn hoặc kết quả của phép tính sử dụng SymPy
* Kiến thức liên quan: CNN, LSTM, Attention, Transformer cơ bản, ViT / ResNet + Attention decoder, fine-tune TrOCR hoặc Donut




2. Kiến trúc & Pipeline
1️⃣ DATA PIPELINE
1. Chuẩn hóa cấu trúc dataset
Bạn phải đưa mọi dataset (IM2LaTeX, CROHME, synthetic) về cấu trúc thống nhất:
Việc cần làm:
* Mapping từ tên file ảnh → LaTeX tương ứng

* Loại bỏ sample lỗi (ảnh hỏng, LaTeX không parse)

* Chuẩn hóa LaTeX (remove BOM, standardize spacing, unify \left \right …)

(cần EDA nữa)
2. Tiền xử lý ảnh
Các bước:
(a) Resize + Padding (chuẩn cho CNN/Vision Transformer)
   * Giữ aspect ratio

   * Pad về kích thước cố định (ví dụ 256×512)

(b) Chuẩn hóa độ sáng, nhị phân hóa (nếu là handwriting CROHME)
      * Gaussian blur

      * Adaptive threshold

(c) Augmentation (cực quan trọng để tránh overfitting)
         * Random rotation ±3°

         * Elastic distortion (cho handwritten)

         * Affine transform

         * Random thickness

4️⃣ EVALUATION PIPELINE
11. Metrics
Bạn cần report đầy đủ:
✔ Exact Match Accuracy (quan trọng nhất)
Công thức output so sánh chuỗi LaTeX đúng 100%.
✔ BLEU Score
Đo mức độ giống nhau của chuỗi.
✔ Edit Distance
Cho biết số phép insert/delete/substitute cần thiết.
✔ Structural Accuracy (optional)
So sánh dựa trên parse tree (khó).
✔ SymPy Equivalence
Đánh giá mức độ tương đương toán học, ví dụ:
\frac{1}{a+b} == \frac{1}{b+a}


Hai công thức khác nhau nhưng tương đương.
________________


12. Error Analysis
                                       * Xác định lỗi ký tự: missing {}, sai chỉ số, nhầm dấu

                                       * Lỗi layout: fractions, matrices, integrals

                                       * Lỗi ảnh: nhiễu, mờ, bị crop

Bạn cần vẽ heatmap attention để xem mô hình nhìn vào đâu.


III. Các mô hình so sánh chính
Mã
	Kiến trúc
	Đặc điểm
	(A)
	CNN + BiLSTM + CTC
	Baseline OCR kinh điển cho chuỗi ký tự, nhanh và nhẹ.
	(B)
	ResNet Encoder + Attention Decoder (autoregressive)
	Học mối quan hệ không gian, mô hình mạnh mẽ cho layout 2D.
	(C)
	ViT Encoder + Transformer Decoder (2D positional)
	Toàn attention, dùng 2D positional encoding để hiểu cấu trúc toán học.
	(D)
	OCR-free (DONUT-style)
	Vision encoder + LM decoder (BPE LaTeX) — không cần CTC, thuần seq2seq.
	

IV. Các yếu tố ablation cần kiểm thử (không biết cái này là gì)
                                          1. Tokenizer: ký tự (char-level) vs BPE LaTeX (subword).

                                          2. Positional encoding: 1D (chuỗi) vs 2D (hàng/cột trong ảnh).

                                          3. Image augment: blur, noise, contrast, perspective, rotation.

                                          4. Training: Teacher Forcing + Scheduled Sampling.

                                          5. Loss: Label smoothing (ε=0.1–0.2) vs Focal loss (γ=2).

V. Dataset & tạo dữ liệu 
                                             * Public datasets: (chatgpt bảo nấy dữ liệu hơi ít)
                                             * CROHME ~ 10k dữ liệu
                                             * Handwritten Mathematical Expressions
                                             * ảnh viết tay tự convert label MathML -> Latex để dùng
                                             * im2latex-100k ~ 100k dữ liệu
                                             * IM2LATEX-100K
                                             * ảnh in + LaTeX chuẩn.

                                                * Synthetic dataset (tự sinh): (này để tự sinh thêm ảnh để train)
                                                * Render LaTeX với các loại font, kích thước, nhiễu khác nhau.
                                                * Sinh tự động các công thức đa dạng: đạo hàm, tích phân, ma trận, giới hạn,…
                                                * Augment bằng nhiễu Gaussian, blur, JPEG artifacts, background texture.
                                                * Mục tiêu: tạo biểu thức OOD (out-of-distribution) để kiểm tra khả năng tổng quát hóa.



VI. Đánh giá mô hình 
Tiêu chí
	Mô tả
	Exact LaTeX Match
	% mẫu trùng 100% chuỗi LaTeX.
	Edit Distance (token)
	Levenshtein distance giữa chuỗi dự đoán và ground-truth.
	AST/MathTree Match
	So khớp cấu trúc cú pháp sau khi parse LaTeX.
	SymPy Equivalence
	So giá trị giữa hai biểu thức tại 100 điểm ngẫu nhiên.
	Robustness
	Test khi thêm nhiễu/blur/contrast.
	OOD Generalization
	Biểu thức dài, cấu trúc lạ hoặc ký hiệu hiếm.
	Speed / VRAM
	Latency và mức tiêu thụ bộ nhớ (8GB / 12GB).

X. Các điểm cần đặc biệt lưu ý
                                                            * Parser LaTeX → SymPy dễ lỗi cú pháp, cần bước chuẩn hóa (normalize) trước.

                                                            * Với ViT hoặc CNN grid encoder, phải giữ 2D layout để mô hình học không gian.

                                                            * Không chỉ đánh giá Exact Match – SymPy equivalence mới phản ánh hiểu biết toán học.

                                                            * Quản lý VRAM (FP16, batch nhỏ, gradient checkpointing).

                                                            * Đảm bảo reproducibility: cùng seed, config, và log đầy đủ (W&B, MLflow, CSV).
